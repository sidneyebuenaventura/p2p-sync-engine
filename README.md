# p2p-sync-engine

A generic procure-to-pay integration engine that keeps three kinds of business
systems in step:

- **procurement**: where suppliers, requisitions and invoices are approved
- **erp**: where vendors and AP invoices are posted to the ledger
- **maintenance**: where work orders and service requests originate

> 🚧 Work in progress. Full documentation and a runnable demo are on the way.
